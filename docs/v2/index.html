VERSION 02 / ORIGINAL COURSE PROTOTYPE · ARCHIVED

Four identities.
One classical signal path.

The original transform-domain audio watermarking project: encode one of four identities into a 32-position redundant codeword, embed it with spectral QIM, and detect it blindly after real MP3 processing.

V2 establishes the engineering foundation for later versions. The effective identity payload is 2 bits; the redundant 32-bit carrier must not be confused with 32 reliable message bits.

01 / METHOD

How the first version worked

A simple, explainable DSP system with a strict four-identity message contract, later generalized in V3.

01 / IDENTITY

Two useful bits

Encode one of four preset labels with source bits a, b.

00 · 01 · 10 · 11
02 / REDUNDANCY

Fixed 32-bit codeword

Repeat the source bits and their XOR over 32 physical code positions. Codebook minimum Hamming distance is 21.

[a×10, b×11, (a⊕b)×11]
03 / EMBEDDING

FFT/QIM carrier path

2048-point non-overlapping FFT frames. Modulate A/B log spectral magnitudes while retaining phase.

REAL_TOP32 / 1000–10000 Hz
04 / DECODING

Blind identity decision

Compare received bits to legal identity codewords. Reject as UNKNOWN when the distance is too large or tied.

rejection distance > 8

Explore the fixed identity codebook

The actual V2 mapping is deterministic. It illustrates how four labels use 32 physical code positions to withstand a limited number of bit errors.

IDENTITY 000 × 32

All-zero codeword.

IDENTITY 010 × 10 / 1 × 22

Second source bit and XOR block become ones.

IDENTITY 101 × 10 / 0 × 11 / 1 × 11

First source bit and XOR block become ones.

The fourth identity (11) has its first 21 positions set and its XOR positions zero. Each of the four fixed words is uniquely represented, but only 2 bits identify a message.

The key observation: Strong redundancy gives the four predetermined identities much greater robustness than unrestricted arbitrary-message recovery under the same broad DSP family. V2 therefore motivated V3's choice to trade part of the physical code space for an 8-bit variable message.
03 / HISTORY & SCOPE

What stayed—and what changed

What V2 already established

Deterministic message-to-codeword mapping, frequency-domain embedding, a blind detector that receives no original signal, and real FFmpeg MP3 round trips.

Historical 6/15/30-second modes remain in the teaching demo. Only 6-second, single-block recordings belong to the formal frozen positive-source validation table.

What V3 added

V3 retained the fixed FFT/QIM approach while upgrading to 256 variable messages, a fixed Boolean-evaluation subcode, and continuous soft-decision statistics. Its 117/120 MP3 accepted-exact result is from a different protocol and should not be directly compared to V2's 46/48 identity score.
