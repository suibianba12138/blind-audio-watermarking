01 / SIGNAL PATH

A fully traditional DSP pipeline

V3 does not depend on a neural model. Its watermark travels through frequency-domain amplitude modification and a fixed public 8-to-32-bit code. Blind detection uses the received audio, public configuration and a preshared selector—not the expected answer.

01 / MESSAGE

8 useful bits

Choose any integer 0–255. Encode it into a fixed 32-bit Boolean-evaluation subcode rather than placing eight unprotected bits directly.

256 distinct messages
02 / CARRIER

REAL_TOP32

Use a frozen 32-group spectral carrier selection map. Each physical bit is embedded in four FFT frames.

FFT=2048 · 48 kHz
03 / EMBED

Log-magnitude QIM

Move the A/B spectral log-magnitude difference toward bit-dependent quantization lattices, while preserving the phase.

strength = 1.60
04 / DETECT

Soft correlation

Aggregate continuous per-bit detection statistics, score all 256 legal codewords and accept only if the frozen presence rule permits it.

threshold = 0.785507
Why is the code needed? The earlier 32-bit arbitrary message path was not reliably recoverable after MP3. Reallocating 32 physical positions to only 8 effective message bits allows redundancy and soft decoding. The gain is robustness under a narrower payload contract—not a claim of general 32-bit reliable transfer.

What the comparison shows: Under this architecture and protocol, the stronger 8-bit redundancy outperformed the tested 12-bit candidate. It does not establish the global channel capacity, the optimal DSP algorithm, or the limit of all classical watermarking methods.

Presence detection

Frozen presence gate; 0/60 clean false positives and 1/60 MP3-clean false positive in the finite controls. Wrong-key MP3 acceptance was 0/120. An UNKNOWN response is a legitimate rejection, not an implicit successful decode.

Audio quality

A formal controlled listening study was not established for V3, so these results do not prove that its watermark is imperceptible. They also do not warrant an unqualified claim that V3 is near the limit of traditional DSP.

04 / WHY V3 MATTERS

What we learned on the classical path

The value of V3 lies in the engineering constraints and trade-offs it made measurable.

From V2 to an arbitrary 8-bit message

Legacy V2 provides only four predetermined identities, i.e. two bits of useful identity information. V3 raises the effective message space to 256 values while remaining a fully blind DSP pipeline.

Carrier selection, code redundancy, and using continuous rather than only hard bit decisions address observed MP3 distortions within the frozen transform-domain approach.

Read V2 method history ↗

Why move on to V4?

V3 provides strong bounded six-second MP3 evidence at an 8-bit payload, but increasing effective payload reduced reliability in the evaluated 12-bit candidate. V4 explores a different, third-party pretrained neural model at 40 bits, 12 seconds and MP3/AAC.

V3 and V4 results come from different protocols. They should not be interpreted as an apples-to-apples leaderboard.
