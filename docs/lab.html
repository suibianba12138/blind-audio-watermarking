HOW TO READ THIS DEMO

本实验实际调用 C2/C3 参考辅助水印嵌入、FFmpeg 信道处理和参考辅助检测。FFT 和图表由浏览器对当前任务产生的音频文件计算；完成后播放的是可视化讲解，不是假装实时逐帧运行。上传音频的可视化预处理采用浏览器解码，与后端 FFmpeg 转单声道/重采样可能有微小差异。MP3/AAC 可能带有解码时延，信道前后叠加图不作为严格样本对齐的检测残差。检测结果来自本次后端响应，不使用历史 CSV。
